# Protocol: Links

Part of [[core]].

- Link with Obsidian wikilinks, never in frontmatter or card heading/Repos/Tickets lines. This covers handoff cards, ticket files, repo profiles, ideas, notes, knowledge and threads lines.
- Link a file only when its content is what the entry relies on, with a short reason next to the link; never link because a name appears. Candidates: the repo profile (`[[<repo>]]`) and ticket file (`[[<KEY>]]`) the work is about, the handoff file it came from (`[[handoffs/<name>|<name> handoff]]`), and related ideas, notes or knowledge.
- Cards use the `Links:` line; ideas use `## Links`; ticket files, notes and knowledge end with a `Links:` line; repo profiles list their ideas and knowledge under `## Links`; a threads line may link inline.
- Link only files that exist, or the one you are creating.
